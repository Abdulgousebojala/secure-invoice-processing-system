# secure-invoice-processing-system
Enterprise backend automation system for secure invoice management, report generation, and email automation using Spring Boot and React.

# Features
JWT Authentication & Spring Security
Secure Employee Login & Registration
Invoice Management System
Automated Excel Report Generation
Quartz Scheduler Automation
Automatic Email Notifications
MySQL Database Integration
REST API Development
Modern React Dashboard UI
Enterprise-style Full Stack Architecture


#Tech Stack
## Backend
Java
Spring Boot
Spring Security
JWT Authentication
Spring Data JPA
Hibernate
Quartz Scheduler
Apache POI
Spring Mail
MySQL

## Frontend
- React
- Vite
- Tailwind CSS
- Axios

## Tools
- Git & GitHub
- Postman
- MySQL Workbench
- VS Code

#  Project Workflow

1. User registers and logs in securely.
2. JWT token is generated after login.
3. User creates and manages invoices.
4. Invoice data is stored in MySQL database.
5. Quartz Scheduler automatically fetches invoice data.
6. Apache POI generates Excel reports.
7. Spring Mail sends reports automatically through email.

# Authentication Flow

User Login
JWT Token Generation
Token Validation using JwtFilter
Protected REST APIs using Spring Security

# Automation Features

Automatic Excel report generation
Scheduler-based report processing
Email automation using Spring Mail

# How To Run The Project:

## Backend
mvn spring-boot:run

Backend runs on:
http://localhost:8080
